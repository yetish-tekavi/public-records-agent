## 7. Notes and limitations

- The planner is `rule-based` (deterministic). The Claude planner exists but was not used: it needs Anthropic credentials.
- The missing-evidence scenario restricts the corpus to one real document rather than stubbing the retriever.
- Exception detection is keyword-based: it quotes any exception language that follows the provision within the same subsection, which can include clauses that do not qualify the redaction rule. The reviewer decides.
- Recommendations are evidence for a human reviewer, not legal determinations.
- The agent's own search used the planner's wording ("What New Jersey law applies when a public record contains a person's personal telephone number?"); the TA's exact wording was run in section 2. The planner avoids "someone" because that word never occurs in the corpus, which makes keyword retrieval veto every match (see the keyword-only comparison in section 2).
